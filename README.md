# Wanderly — Travel & Tourism Website

## Objective
Wanderly is a responsive travel inspiration website built for the Web Development and Cloud Foundation MSE. It helps visitors explore destinations, choose travel experiences, save places, and try a demo trip-planning form.

## Features
- Responsive layout for desktop, tablet, and mobile screens
- Mobile navigation menu
- Destination cards with images and save/unsave interaction
- Experience selector with JavaScript-generated travel ideas
- Demo trip-planning form with basic validation and confirmation
- Semantic HTML and accessible labels
- Smooth scrolling and reduced-motion support

## Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, media queries)
- Basic JavaScript (DOM selection, event listeners, arrays, conditionals, form validation)

## Run Locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. An internet connection is needed for the Google Font and remote Unsplash images.

## Deployment on Vercel
1. Upload the project files to a GitHub repository.
2. Sign in to Vercel and choose **Add New → Project**.
3. Import the GitHub repository.
4. For this static website, leave the build command empty if Vercel does not require one; the output directory can be the project root.
5. Click **Deploy** and wait for the deployment to finish.
6. Open the public URL and test navigation, destination saving, the experience selector, and the form.
